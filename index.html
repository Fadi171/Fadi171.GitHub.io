Section C

Architecture Overview

Every request follows the same path. Only the edge decides whether the origin is contacted.

1

User Browser

Requests https://<accelerated-domain>/…. It may also keep its own private browser cache.

2

Accelerated Domain

A hostname you own (e.g. cdn.example.com) whose DNS CNAME points to the CNAME generated by Alibaba Cloud, so DNS routes users to a nearby edge.

3

Alibaba Cloud CDN Edge

Terminates HTTPS, applies cache rules (TTL per path/extension), answers from cache on a hit, or goes back to origin on a miss.

4

GitHub Pages Origin

Serves the source files from the repository at <username>.github.io. The CDN sends that value as the back-to-origin Host header.
